# Fase 1: MVP Mínimo

Esta fase se centra en construir el Producto Mínimo Viable (MVP) para validar la idea de negocio.

## Estructura de Carpetas

- **/semana-1**: Contiene la configuración de la infraestructura inicial y el código del bot de Telegram.
  - **/infra**: Archivos de configuración de Docker (`docker-compose.yml`) y la base de datos (`init.sql`).
  - **/bot-telegram**: Código fuente del bot de Telegram.
- **/semana-2**: Código para la lógica de negocio (matching) y flujos de publicación.
- **/semana-3**: Scripts y documentación para las pruebas y el programa de beta testers.
